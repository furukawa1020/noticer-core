# 回復例の公開入力領域

| 最初の枠 | 回復枠 | 公開文脈 | 厳密版の期限 |
|---|---|---|---|
| 利用可能 | 利用可能 | normal | slot 0 |
| 利用不可 | 利用可能 | recovered | slot 1 |
| 任意 | 利用不可 | out-of-scope | 未定義 |

この実験では、回復枠の利用可否を含む二つの公開文脈がモデル開始前に
確定している。受信ログの欠落から利用可否を推測して遡及的に分類しない。
最終枠の利用可能性が確認できない場合は、正常に実行できた例も契約内と
数えない。とくに送信後の損失は、ここでいう送信機会の欠落とは別条件である。

Studioの公開合成デモでは契約を切り替えられる。実プロトコルや人のデータの
実験とは区別し、対象外を失敗件数や成功率に架空追加しない。
