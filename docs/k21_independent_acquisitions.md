# K21: 独立収録の適格性

これは収録データの採否を判断するプロトコルであり、特定データセットが
適格であるという報告ではない。

## 記録単位

- 収録回は参加者ごとの収録手順が開始され、終了した一連の測定とする。
- 一収録内の区間、再分割されたファイル、スライディングウィンドウ、
  ラベル切替は別収録と数えない。
- 接続切断と再開だけで新しい収録回を作らない。
- 独立収録の根拠が未確認なら `unknown` とし、確認済みの回数には含めない。
- 被験者内の収録間に依存があり得る。分割の単位と信頼区間の独立単位を区別する。

## 採否チェック

1. 管理元の収録手順、データ辞書または管理者が収録境界を説明できること。
2. 由来が同じ抜粋・再保存・重なった区間を同じ収録グループへ束ねること。
3. 閉集合本人性評価では、各対象に学習・検証・テストへの別収録割当が必要。
4. 同一人物の別セッションリンク評価では、各分割で同一人物ペアと異なる人物ペアの
   両方を独立収録から構成できること。
5. 動作で層別した後、各評価対象層に必要な対照と観測数が残ること。

| 状態 | 処理 |
|---|---|
| 条件を確認でき、必要数を満たす | 登録済み評価への入力候補。収録独立性や対象者への一般化を別途記載する |
| 条件を確認できるが必要数に届かない | 該当する評価を `inconclusive` とし、予備検証と区別する |
| 由来や収録境界が確認できない | 確認済み収録として数えない |
| 割当で収録グループをまたいで混入した | 評価を `invalid` とする |

公開資料に載せるのは対象数、収録回数区分、適格性と除外理由の集計のみ。
元の識別子、日時、ファイル名、生波形は公開しない。
