# K21: 負の結果を保持する公開比較表

分母は結果取得前に固定した手法 × 観測者 × エンドポイントのセル集合とする。
集計済みの数値表だけでなく、同じセル集合の状態一覧も公開レビューに含める。

| 状態 | 表示する値 | 必須説明 |
|---|---|---|
| `measured` | 推定値、区間、独立単位数 | 証拠分類とレシート |
| `failed` | 公開可能なら境界を超えた指標 | どの事前条件を満たさなかったか |
| `invalid` | 判断に使用しない | 入力・分割・契約違反の理由区分 |
| `inconclusive` | 有効な部分集計のみ | 不足、打切り、又は区間が判定境界をまたいだ理由 |
| `not-applicable` | 数値なし | 事前に決めた比較不能条件 |
| `missing` | 数値なし | 未報告のセルであること |

欠落セルを行から削除しない。NaNや0で欠落を隠さない。
図表で扱う部分集合には、状態一覧への参照と含めなかったセル数を記載する。
Fixtureと実測を横断した平均や順位は公開しない。
