# K7 longitudinal leakage gate

Repeated authorized claims have allowed leakage. This gate reports that total
separately from full-trace observed leakage and their excess. The confidence
interval is estimated for the paired sequence as a whole; per-bucket intervals
are not naively added.

Incomplete attacks or a blind leaky control make evaluation invalid. Rejected
composition, an undetected longitudinal counterexample, or a paired excess
lower endpoint above threshold blocks the implementation claim.

GO_CANDIDATE is never a security proof. This bounded accounting is not general
Pufferfish or differential-privacy composition.
