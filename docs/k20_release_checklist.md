# K20 公開チェックリスト

このチェックリストは判定の前提を確認するもので、実測結果や実装全般の
プライバシー保証を示すものではない。

1. 実験の登録版、評価対象、観測境界、比較手法、閾値を固定する。
2. データの利用許可と独立収録の根拠を確認する。分割と前処理のfit範囲を照合する。
3. 全比較セルと正負の対照を検査する。欠落・不正・打切り・失敗を互いに置換しない。
4. 効果量、独立単位を使った区間、多重比較、動作・実用性・期限の判定を確認する。
5. 全チェックの出所が同じ実験記録に束縛されていることを照合してから判定器に渡す。
6. 公開集計と許可範囲を点検し、digestを照合する。合成の数値は常に合成と記載する。
7. 独立再実行を確認し、査読用成果物を公開用アカウントやログと分ける。
8. レビュー済みの評価範囲だけで結論を書く。判定器の `verified` を普遍的な
   セキュリティ保証、匿名化保証、データ公開許可として扱わない。

先に合成成果物の再現を確認できる。実測の同意、計測記録、登録済み入力が未確認なら、
実測の主張は保留する。
