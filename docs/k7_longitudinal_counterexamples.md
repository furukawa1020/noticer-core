# K7 longitudinal composition counterexamples

Five frozen negative families exercise the real handoff and compatibility
gates: observer-state mismatch, private-cache carryover, secret-retry
carryover, service-collusion mismatch, and a private epoch/key transition.

Private carryover is rejected by the closed parser. Public mismatches are
rejected by stable compatibility dimensions. Epoch changes are accepted only
through the declared public epoch and key-epoch fields.

These bounded counterexamples demonstrate specific failure detection. Passing
them is not evidence for arbitrary longitudinal or concurrent composition.
