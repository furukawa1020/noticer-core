# K21: ベースラインの共通運用予算

比較の対象は特定の設定を持つ手法であり、手法群全体の優越を示すものではない。
数値上限は利用場面から事前に定める。この文書は上限値や実測結果を固定しない。

| 予算軸 | 比較上の規約 |
|---|---|
| 遅延 | 受付から実行結果までを同じ単調時計で測る。観測終了時に未完了なら別計数する |
| 帯域 | 同一観測窓の実データ、パディング、フレームの諸費用、再送を同じ層で数える |
| 動作 | 動作の種類と引数、安全判断、復旧義務を比較する。一致しない例を性能平均から隠さない |
| 期限 | 同じ受付・期限・外部イベントを使い、完了、遅延、未完了、打切りを別に集計する |
| 稼働条件 | 同じ外生入力・障害シナリオを対応付け、手法固有の乱数と外部の乱数を分離する |

設定選択は事前指定の開発条件で行う。テスト結果を見て予算や設定を選び直さない。
共通制約を満たさない手法は `budget-failed` として理由付きで残し、
共通制約内の性能比較と混同しない。そもそも比較できない行は
`not-applicable`、欠測や打切りで判定できない行は `inconclusive` として区別する。
