# K22: 査読向け回復トレース成果物の範囲

公開デモは事前に合成と明示した値だけを表示する。査読用スナップショットは
公開デモのリポジトリと直接結び付けない。双方の公開は別の決定として扱う。

| 区分 | 査読用コピーに含める値 | 除外する値 |
|---|---|---|
| 入力 | 合成の公開障害列、論理スロット、合成で使用する有限の機械表 | 原波形、参加者情報、正確な収録時刻、利用許可外データ |
| 証拠 | 合成モデル、入力とモデルのdigest、機械判定、最短反例、合成の受信ログ | 生体信号由来の行データ、研究者・ホストの識別子 |
| 再現 | 匿名の実行コマンド、許可された依存バージョン、期待する合成結果 | Git履歴、元のremote、公開バッジ、個人名、絶対パス、ログを収集するリンク |

匿名性はこの一覧だけでは保証されない。スナップショットを作ってから、
ファイル名、ソース、生成物、コンテナレイヤー、配布先の所有者表示を
別担当が確認する。受信者の観測範囲もREADMEに明記し、実機や実プロトコルの
保証に読み替えない。匿名スナップショットの発行・外部公開は未実施。
