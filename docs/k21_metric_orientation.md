# K21: 評価指標の向きと判断単位

比較表には指標、単位、測定対象、方向、基準、証拠分類を記す。
同じ指標名でも観測者や動作階層の違いは別の評価セルとする。

| 指標 | 測定単位と基準 | 読み方 |
|---|---|---|
| 本人性のbalanced accuracy | 凍結したクラス集合。均一な当て推量の基準はクラス数の逆数 | 高いほど推定性能が高い。単独の低値を匿名性の保証としない |
| リンク可能性ROC AUC | 同一人物ペアが正例。正方向の偶然基準は0.5 | 生のAUCと、0.5からの距離を別欄にする。向きが逆のスコアでも漏洩は残り得る |
| TPR at FPR | 検査対象の低FPR値を先に固定 | 負例数が設定値を解像できなければ未定義。試験曲線から運用閾値を選ばない |
| 期限内完了率 | 受け付けた義務が分母 | 高いほどよい。打切り件数を併記する |
| 遅延 | 受付から完了までのns。完了観測の条件付き分位点 | 低いほどよいが、完了率の低下と相殺しない |
| 通信量 | 同じ観測窓の総バイト数 | 低いほどよいが、許可済み動作の消失とは引き換えにしない |

対応差は改善が正になるように向きを揃え、元の単位を維持する。
信頼区間はペア構成要素の再利用を考慮し、同じ参加者や収録を共有する行を
独立反復として水増ししない。
