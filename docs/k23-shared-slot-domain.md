# K23: The shared-slot evidence boundary

This is a finite synthetic scheduling model, not a protocol or physiological
experiment. A logical slot is not a measure of network latency.

| Condition | Evidence allowed |
| --- | --- |
| A complete, declared public tape | Offline matching or a checked Hall deficit |
| Two public continuations with a common first-slot view, two slots total | A checked first-choice separation and the corresponding minimax statement |
| A missing public availability entry | Invalid input, not a deficit |
| An enumeration cut off before both decision sets are complete | Inconclusive, not verified |
| Variable-size or preemptible actions, unsignaled availability, late releases, or measured losses | Not evaluated |

Offline allocation assumes the entire declared tape is known. The two-slot
minimax guarantee additionally assumes the future is fixed before policy
randomness; with more slots, a common completable first choice alone does not
prove a common causal continuation. A Hall witness instead proves impossibility
even when the future is known. Neither witness proves production AETP.
