# K22: 回復機構を比較する二つの非生体ユースケース

どちらも公開用途を模した合成モデル。実在の機器や通知事業者での試験ではない。

| 用途 | 許可された動作 | サービスへ渡すもの | 回復時に比較する義務 |
|---|---|---|---|
| 照明の場面切替 | 既に許可された部屋の照明を一度だけ暖色設定にする | 行動ID、論理枠、認可済み受領結果 | 再送で別プロファイルを適用しない。先に期限が来る通知と帯域競合する場合は期限違反を残す |
| 通知の配信 | 刺激を抑えた通知を一つだけ表示する | 一般化した通知種別、論理枠、認可済み受領結果 | 再接続後も同じ行動を二重表示しない。照明側のログを足しても、許可行動に不要な準備情報を渡さない |

`test_recovery_distinct_deadlines` は異なる窓の有限テープに対し、
準備時刻がどちらでも正規化受領が一致し、一方の期限を他方に合わせて
黙って延長しないことを検査する。`test_recovery_capacity` は1レーンの場合に
独立レーンの結論が成立しないことを示す。これらを用途全体の保証に読み替えない。
