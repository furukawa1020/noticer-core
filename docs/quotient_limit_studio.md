# QuotientLimit Studio

`/quotient-limit` は、QuotientLimitの有界小モデルを説明する対話画面である。研究結果そのものやdeployment trust anchorではない。

## 操作

- 2つのprivate ready timeとaction quotientを編集する。
- deadline、observer、fault、privacy mode、cost、collusionを切り替える。
- `SOLVE QUOTIENT`で最小release slotまたはinfeasibility coreを表示する。
- certificateを独立操作で再検証する。
- certified lower boundとQuotientLimit、参考比較のAETS/APLOTをfrontier上で分離表示する。

画面と計算核はprivate biosignal、baseline、stable identifierを入力・保存・出力しない。近似privacyと既存stack比較は説明用の有界モデルであり、科学的評価artifactではない。
