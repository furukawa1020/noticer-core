# K7 adaptive attack claim-stop gate

The gate consumes content-addressed runtime capture, corpus, attack protocol,
leakage report, and leaky-control report inputs. It applies one fixed fail-closed
decision order.

An incomplete evaluation or undetected leaky control is INVALID_EVALUATION.
Pointwise trace inequality is BLOCKED regardless of classifier performance.
A full-trace-minus-claim-only confidence interval whose lower endpoint exceeds
the frozen threshold is also BLOCKED. Only the absence of these registered
refutations produces GO_CANDIDATE.

GO_CANDIDATE permits continued implementation-claim work but is never a security
proof. The artifact always stores security_proof=false. Generated gate JSON is
canonical, digest-bound, and belongs under artifacts rather than Git.
